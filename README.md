# boardgames — інтернет-магазин настільних ігор (backend)

Самостійна робота до занять 1.1 і 1.2 (повний CRUD + фільтр за жанром). Spring Boot 3.4.x, Java 21, Maven.

Ендпоїнти: `GET /api/games[?genre=]`, `GET /api/games/{id}`, `POST /api/games` (201), `PUT /api/games/{id}` (200/404), `DELETE /api/games/{id}` (204/404).
Приклади — у `requests.md`. Тести: `./mvnw test`.
